# Code of conduct

Be respectful and constructive. Harassment, discrimination and personal attacks are not tolerated. Critique code and
ideas, not people. Maintainers may remove comments, commits or contributors that violate this. Report concerns to the
maintainers through a private GitHub security advisory or a direct message to the repository owner.

This project follows the spirit of the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
